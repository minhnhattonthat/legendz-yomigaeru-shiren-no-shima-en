# Debug tool: how warping works

Command in `AGENTS.md`. Files: `tools/debug/warp.lua`, `scenes.lua`, `virtual_doll.lua`. Regenerate shots and states: `python -X utf8 tools/debug/regen.py`.

## Mechanism (verified: first warp `work/qa/w1`, Small Cave at frame ~900)

The whole game is scripted on the VM (`docs/re/script.md`): each room is one script, entered by `00F2 <ptr>` (change scene), with the entrance number in `0x03006270`.

1. From a cold boot `warp.lua` presses Start while `0x0203BD98` (main mode) is `0x11`, the title screen. It tests RAM, never a frame count.
2. When the mode reads `0x0B`, the title menu, it presses Down then A. The menu writes `8` for New Game (`0x080CEB0A`), and the warp errors out on any other value. Task 0 then runs native `0x08092A09` (guess: the new-game init, from where it sits in the flow). Don't poke the `8`: that skips the menu's cleanup and the title's ribbon sprite stays on screen for the whole run.
3. New game's first `00F2` targets `0x0802483A`. A hook at `0x0808B8B8`, right after the handler stores the pointer in the task PC, swaps in the scene's script and entrance and applies its flags and RAM writes.

Nothing else is patched, so the scene plays as the game plays it, and `F2`'s own flag resets run.

## Partner

A warp with `partner = true` copies the writes the real Reborn made (`tools/debug/partner.lua`, generated by `capture_partner.py` from two RAM dumps, doll byte `0x2C`) and sets flag `0x15F`. Scenes in the cave leave it off, so the doll path itself can be tested. Not yet shown: that a battle runs correctly with this partner.

## Known limits

- **What `REACHED` proves:** the warp fired. It doesn't prove the room is right; read `work/qa/scenes/proof*.png`. A room entered this way shows no story state: flags are unset unless the scene lists them, so people and events may differ from a real playthrough.
- **Start does nothing in Legendz Town reached by warp** (scene `town`, key sent at frame 1901, no menu). Cause not found. It does open in Small Cave, so `field_menu` and `talispod` go there.
- **Not in the list yet:** see `status.md`.
